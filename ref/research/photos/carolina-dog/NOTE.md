# Carolina Dog: photo search (Photographer, Oct 7, 2026)

**Status: paused** (GrumpyDingo moved the Carolina Dog down the list; the Siberian Husky and Alaskan Malamute come first). Nothing is catalogued yet because **no usable side view was found**. This note records the search so it doesn't have to be repeated.

## Searched
- **Openverse** (licence by, cc0, pdm): `Carolina dog`, `American dingo`, `Dixie dingo`, `Carolina yellow dog`, `carolinadog`, plus tags `carolinadog`, `americandingo` and `carolina dog`, and the Commons source alone. That gave 530 hits. Almost all were dogs *in* the Carolinas: police K9s, State Farm, USMC, Bowie's *Diamond Dogs*.
- **Flickr search** (HTML, licences 4, 9, 10 and 11: CC BY 2.0, CC0, PDM, CC BY 4.0): `carolina dog` (6 pages), `american dingo`, `dixie dingo`, `carolina yellow dog`. 134 photos screened on contact sheets. The only genuine Carolina Dogs are SteveMcD's (below).
- **Wikimedia Commons `Category:Carolina Dog`:** licence read from each file page.
- Scout's earlier search (iNaturalist, Openverse, Commons) is in `ref/research/scout/01-body-templates/NOTE.md`. Its finding stands: every iNaturalist "Carolina" observation is NC or unlicensed.
