# Xoloitzcuintli (Mexican hairless dog)

Part of Firefly's Oct 7 request for new pose values `muscle-ref`, `top` and `front`
(see `../MUSCLE-TOP-FRONT-NOTE.md` for the overall search, rejects and gaps).
Pose meanings: `muscle-ref` = side-on (or near side-on) photo where little fur hides muscle shape;
`top` = dorsal / high-angle view for body width; `front` = front-on standing view for chest/body width.
Every licence was checked on the individual Flickr photo page (embedded `license` code of the main photo model),
Commons file page (licence template) or iNaturalist API `license_code`. Sizes: Flickr originals and Commons
originals mostly returned HTTP 429, so the largest size that downloaded is used; each catalogue row says which.

## What is here
- `muscle-ref/` 13: best are 05/06 (Canarian, Commons CC BY 4.0: standard hairless xolo stacked side-on on a plain ring floor),
  07 (Svenska Mässan, plain backdrop), 13 (MyDOG stack, breed inferred by eye), 01 (CDMX culture ministry, walking side-on).
- `front/` 2: Pets Adviser Westminster photos (via Commons, CC BY 2.0) of a xolo standing nearly square to camera.

## How I searched
- Flickr (licence 4,9,10,11): "xoloitzcuintli", "xoloitzcuintle", "xolo dog", "mexican hairless dog" (~112 hits); user streams
  Svenska Mässan (36333395@N06) and Pets Adviser/Petful (88954214@N04).
- Openverse: same terms (~180 hits, overlap with Commons/Flickr).
- Commons: Category:Xoloitzquintle (51 files), Xoloitzcuintle dogs at the Dolores Olmedo museum (23), Hairless dog breeds (15).
- Screened ~350 thumbnails by eye on contact sheets.

## Rejected (quality / not a real live dog)
- Statues, ceramics and murals (Colima dogs, Xico sculptures, garden bronzes), puppies, coated xolos, heavy crop/occlusion.
- Isoxolokarvallinen1/3 are COATED xolos (CC BY 4.0) - not used for muscle.
