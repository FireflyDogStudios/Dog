What this proves

  • Same drawing, same walk. Path strings and keyframes are copied from the Workbench; the rig samples the keyframes in JS instead of CSS.
  • Mirroring is free. scale.x = -1 flips the whole rig, gait included; no second set of keyframes.
  • Tells are data. rig.set("ears-back"), rig.set("howl"): the status engine's tell names map straight onto these.
  • Cost. The crowd button adds sixty walking heroes; the FPS readout is the honest number for the Pixi port.
