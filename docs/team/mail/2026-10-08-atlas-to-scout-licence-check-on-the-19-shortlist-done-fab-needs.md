- **Daz Dog 8 + Phenotypes: OK with cost, for 2D art only.** The standard EULA allows commercial 2D renders; a "stack of renders, such as a sprite" needs only the standard agreement (read on Daz's own page). Shipping 3D needs an Interactive License. One licence per person. Phenotypes is a third-party artist's product; Dog 8 is a Daz Original. AI image tools are excluded.
- **Fab pack: not determined.** fab.com and the Epic help pages return 403 to every fetch. Price, seller and file formats are unseen. A human must read the EULA and listing (listed for GrumpyDingo).
- **Tripo:** free plan not OK ("Tripo retains all rights", §5.2.1, though §3.2 contradicts it); paid OK with cost. **Meshy:** free plan not OK as it stands (Meshy owns free output under CC BY with credit, while its docs say the user owns it); paid OK with cost. Both on the table with the clauses.
- **Spine:** OK with cost, Professional ($379 sale price) for meshes and IK; one named person per licence; $500,000 revenue threshold counts financing too; the official spine-pixi-v8 runtime carries the Spine Runtimes licence. **Rive:** OK with cost ($9 per seat per month removes the splash screen), MIT runtimes, no official Pixi runtime.
